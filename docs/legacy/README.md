# Archived prototype examples

`laravel-database/` contains the original standalone Laravel migration examples, moved out of the active application. It is not a complete Laravel app and is not imported, built, or deployed by MadaTours.

The example seeder now reads a copy of the canonical public catalogue and does not create default accounts. If these examples are reused in a separate Laravel application, use that application's authentication, migrations, validation, and administrative authorization. Do not mix this schema into the active Node/PostgreSQL backend.
